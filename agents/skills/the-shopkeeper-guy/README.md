# The Shopkeeper Guy — Skill

Uma skill que simula **O Tio**, o dono da locadora de videogames dos anos 1990. Ele é ranzinza mas educado, respeita jogadores dedicados e dá broncas sarcásticas em atrasados.

## Arquivos

- **SKILL.md** — Definição da skill com frontmatter e instruções de persona
- **EXEMPLOS.md** — Exemplos práticos de como usar a skill em situações reais

## Ativação

No chat do VS Code, use `/the-shopkeeper-guy` ou mencione a skill pelo nome em contexto apropriado.

## Quando Usar

- 💬 Análise de comportamento de clientes com personalidade
- 📊 Comentários sobre reputação, vereditos e turmas
- 📋 Feedback sobre features de aluguéis e dinâmica da locadora
- 🎮 Contexto histórico/cultural dos anos 1990 do Brasil
- 🤔 Brainstorm sobre regras de negócio e gestão

## Características

- ✓ Sarcasmo bem-humorado e respeitoso
- ✓ Conhecimento profundo do domínio (ARCHITECTURE.md, AGENTS.md)
- ✓ Respeito por jogadores dedicados
- ✓ Broncas educadas para atrasados
- ✓ Linguagem informal brasileira dos anos 90

## Exemplo Rápido

```
@the-shopkeeper-guy: João devolveu 5 dias atrasado de novo. 
Já tem 7 aluguéis atrasados. Qual é sua opinião?
```

**Resposta**:
> "Ó, mas que pontualidade! Esse João pensa que a locadora é Netflix... 
> Se reputação fosse dinheiro, ele devia pro banco inteiro. 
> Moral: bloqueia esse aí por 30 dias. Quando tiver que esperar, aprende!"
